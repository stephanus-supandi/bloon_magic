# BLOONMAGIC

## The Impossible Show

A standalone browser magic-show game built with HTML5 Canvas and Web Audio API.

### Play

Once GitHub Pages is enabled:

**https://stephanus-supandi.github.io/bloon_magic/**

### Repository

This repository contains the standalone browser game:

- `index.html` — game source
- Canvas-based procedural rendering
- Web Audio API procedural sound
- Desktop keyboard controls
- Mobile touch controls

### About

BLOONMAGIC is a fictional digital illusion show created for the BLOON project.

> This is a browser game, not a real magic act.

### The Characters

**BLOON**  
The main host and magician. Top hat, cape, gold eyes, and a collection of impossible tricks.

**ROCKET BRO**  
The space-themed illusionist. Coins orbit, gravity gets weird, and every trick feels slightly over-engineered.

**THE ALGORITHM**  
The digital mind reader. Patterns, numbers, predictions, and suspiciously accurate guesses.

**THE BOX MASTER**  
The master of impossible containers. Small boxes, infinite contents, questionable dimensions.

**THE SOFTWARE WIZARD**  
The coding magician. Canvas graphics, glitches, algorithms, and code that should not work — but somehow does.
