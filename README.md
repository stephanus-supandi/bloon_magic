# BLOONMAGIC

## The Impossible Show

A standalone browser magic-show game built with HTML5 Canvas and Web Audio API.

### Play

Once GitHub Pages is enabled:

**https://stephanus-supandi.github.io/bloon_magic/**

### Repository

This repository contains the standalone browser game:

- `index.html` — game source
- Canvas-based procedural rendering
- Web Audio API procedural sound
- Desktop keyboard controls
- Mobile touch controls

### About

BLOONMAGIC is a fictional digital illusion show created for the BLOON project.

> This is a browser game, not a real magic act.
